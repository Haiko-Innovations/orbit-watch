# The orbit fit's example

**SIMULATED.** Three simulated stations watch the simulated object 339001 for a day
and see it in the first night's passes, over 3.1 hours:

- `observations/SIM-ESPOO.json`
- `observations/SIM-GRAZ.json`
- `observations/SIM-MADRID.json`

The fit starts from `catalog.json`, the true set moved about 4 km along the track, and
gives `fit.json` ([D-70](../../docs/decisions.md#d-70-orbit-determination-in-the-core)):

```
orbit-watch fit-orbit observations/*.json --catalog catalog.json --out fit.json
```

It uses 25 of 25 observations, with an RMS of
15.19 arcseconds along the motion and 4.63 across it. `orbit-watch demo
--orbit-fit` makes the directory again, and CI compares it byte for byte.

SIMULATED DATA: generated by the Orbit Watch simulator from public or synthetic orbit data. These are not real observations.
